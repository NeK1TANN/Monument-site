# MONUMENT — Сайт гранитной мастерской

Адаптивный двухстраничный сайт для гранитной мастерской полного цикла, занимающейся проектированием, изготовлением и установкой памятников, скульптур и мемориальных комплексов из натурального камня и бронзы.

## Основные возможности и разделы

* **Главная страница (`index.html`):**
  * **Первый экран (Hero):** ключевое торговое предложение и 4 главных преимущества (бесплатный 3D-эскиз, сроки от 14 дней, бесплатное хранение, официальная гарантия).
  * **Каталог работ:** 6 основных категорий изделий с указанием габаритов, материалов и стартовой стоимости.
  * **Направления работы и породы камня:** 6 видов услуг мастерской и каталог натуральных пород (Габбро-диабаз, Дымовский, Мансуровский, Лезниковский, Капустинский гранит, Балтик Грин, Лабрадорит, мрамор Коелга) с реальными текстурами.
  * **Условия и гарантии:** блок доверия с прозрачными условиями оплаты и документацией.
  * **Этапы заказа:** пошаговый вертикальный таймлайн от заявки до установки на участке.
* **Страница оформления заявки (`order.html`):**
  * Автоматическая подстановка выбранного в каталоге изделия через URL-параметры (`?item=...`).
  * Выбор породы камня и предпочтительного способа связи (звонок, WhatsApp, Telegram).
  * Блок прямых контактов, адреса мастерской и режима работы.

## Структура проекта

```text
monument/
├── index.html          # Главная страница
├── order.html          # Страница оформления заявки и расчёта
├── README.md           # Документация проекта
├── css/
│   └── style.css       # Адаптивные стили, сетки (Grid/Flexbox) и CSS-переменные
├── js/
│   └── script.js       # Обработка URL-параметров, валидация и отправка форм
└── images/             # Изображения изделий и текстуры пород камня
```

## Технологии

* **HTML5** — семантическая вёрстка (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`).
* **CSS3** — CSS Custom Properties (переменные цветов), CSS Grid, Flexbox, адаптивность под десктоп, планшеты и смартфоны, плавные анимации и `aspect-ratio` для сохранения пропорций фото.
* **Vanilla JavaScript (ES6+)** — передача выбранного товара между страницами через `URLSearchParams`, обработка отправки форм без перезагрузки страницы.
* **Google Fonts** — шрифтовая пара *Cormorant Garamond* (заголовки) и *Inter* (основной текст).

## Что можно улучшить

* Подключить отправку заявок из `js/script.js` в Telegram-бот или на сервер (через `fetch` / PHP / Formspree).
* Добавить маску ввода для поля номера телефона.
* Заменить демонстрационные контакты, адрес мастерской и реквизиты (ИНН/ОГРН) на реальные данные компании.
